# Патентный радар — интерфейс

Кликабельный прототип КТ1 на заглушках: «Экран запроса», «Выдача» (сводка и карточки похожих патентов), «Карточка патента», «Ничего не найдено», подсказки проверки ввода, «Загрузка», ошибки «Сервис недоступен» и «Запрос отклонён». Стек: Vite, React, TypeScript, Tailwind CSS. Сценарии и точные строки интерфейса — [spec/product/scenarios.md](../spec/product/scenarios.md), контракт API — [spec/tech/architecture.md](../spec/tech/architecture.md). Пути к файлам в этом README — от корня репозитория.

## Дизайн

Концепция — «радар»: интерфейс похож на экран радара, который ищет «цели» — похожие патенты.

- **Темы.** Тёмная по умолчанию: глубокий тёмно-синий фон и бирюзовый акцент. Светлая включается кнопкой в шапке (солнце или луна) — например, когда прототип показывают на проекторе; выбор запоминается в `localStorage`. Цвета заданы переменными в `frontend/src/index.css`; контраст по WCAG AA посчитан для обеих тем: текст не ниже 4,5:1, рамки полей, фокус и полоса релевантности не ниже 3:1.
- **Экран запроса.** Анимированная развёртка радара (вращающийся луч, кольца, шкала, «цели», которые вспыхивают при проходе луча) и крупное поле описания идеи со встроенной кнопкой «Найти аналоги». Радар — SVG и CSS (`frontend/src/components/RadarScope.tsx`), без библиотек анимации.
- **Выдача.** Карточки патентов вместо таблицы: номер и коды МПК моноширинным шрифтом, полоса релевантности (оценка BM25 относительно лучшей в выдаче, число — рядом текстом). Пояснение языковой модели — отдельная заметная панель «Сводка» с метками-ссылками `[ID]`. На широком экране «Сводка» и карточки стоят рядом, на узком — друг под другом.
- **Состояния.** Загрузка — маленький радар и скелетоны в раскладке выдачи; «Ничего не найдено» — радар без целей; ошибки — панели со значком.
- **Карточка патента.** Крупный заголовок, реферат с шириной строки около 68 знаков, метаданные с кодами INID (номер, МПК, год, позиция и оценка) — отдельным блоком: сбоку на широком экране, под заголовком на узком.
- **Шрифты.** Unbounded — заголовки, Manrope — текст, JetBrains Mono — номера, коды МПК, годы и оценки. Все три — вариативные npm-пакеты `@fontsource-variable` с кириллицей, работают офлайн.
- **Движение.** Смена экрана — плавное появление, карточки выдачи появляются по очереди. Если в системе включено «уменьшить движение» (`prefers-reduced-motion`), анимаций нет: развёртка стоит, цели горят ровно.
- **Доступность.** Подписи у всех полей, видимый фокус (у карточки выдачи — обводка всей карточки), работа с клавиатуры, статус поиска для экранных дикторов; декоративная графика скрыта от них (`aria-hidden`). Проверено axe-core (WCAG 2.1 AA) на всех экранах в обеих темах на ширине 390 и 1280.

## Запуск

Нужен Node.js 20.19+ или 22.12+ (`node --version`).

```bash
cd frontend
npm install
npm run dev
```

Откройте http://localhost:5173/ — этот адрес печатает Vite. Адрес `127.0.0.1:5173` может не открыться: dev-сервер слушает только `localhost`. Остановка — Ctrl+C.

С npm 10 (идёт с Node.js 20 и 22; версия — `npm --version`) `npm install` убирает из `frontend/package-lock.json` поля `libc`, и `git status` показывает файл изменённым. Это изменение не коммитьте: верните файл командой `git checkout package-lock.json` (в папке `frontend`). Чтобы lockfile не менялся, ставьте зависимости командой `npm ci`.

## Режимы данных

| Команда | Режим | Откуда данные |
|---|---|---|
| `npm run dev` | `mock` — по умолчанию | `frontend/src/mock/search.json` по правилам заглушки КТ1 (`frontend/src/api/mock.ts`), ответ через ~400 мс; бэкенд не нужен |
| `npm run dev:api` | `api` — файл `frontend/.env.api` задаёт `VITE_API_MODE=api` | `POST /api/search`: dev-сервер Vite передаёт запрос бэкенду на http://127.0.0.1:8000/search |

Текущий режим показан в шапке: «режим данных mock» или «режим данных api». Для режима `api` бэкенд запускают отдельно, из корня репозитория: `uvicorn app.api.main:app --reload` (окружение — по разделу «Запуск» в корневом `README.md`). Если бэкенд не запущен, прокси отвечает кодом 502 и интерфейс показывает «Сервис недоступен».

## Другие команды

Команды выполняются в папке `frontend`:

- `npm run build` — проверка типов (`tsc -b`) и сборка в `frontend/dist/` в режиме `mock`; сборка для режима `api` — `npm run build -- --mode api`;
- `npm run preview` — просмотр собранной версии из `frontend/dist/`, прокси `/api` тот же, что у `npm run dev`;
- `npm run lint` — oxlint, в том числе правила хуков React.

Поле `allowScripts` в `frontend/package.json` записала команда `npm approve-scripts fsevents`: npm 11 просит отдельно подтверждать install-скрипты зависимостей. `fsevents` — наблюдение за файлами в macOS, его использует Vite. Без этого поля npm 11 печатает при установке предупреждение `allow-scripts`; на работу оно не влияет, более старые версии npm поле не читают.

## Мок и заглушка

`frontend/src/mock/search.json` — ответ API на основной демо-запрос, его же возвращает заглушка бэкенда `app/api/stub.py`; совпадение проверяют тесты `tests/test_api.py`. Остальные ответы `frontend/src/api/mock.ts` строит по тем же правилам, что заглушка: демо-тема по основам слов, фильтры по году и префиксу МПК, `top_k`, в `answer` — только абзацы об оставшихся патентах. Демо-записи `DEMO-001` … `DEMO-003` не реальные патенты; менять их нужно согласованно в `data/sample/patents.jsonl`, `app/api/stub.py` и `frontend/src/mock/search.json`.

Интерфейс ничего не загружает из интернета: шрифты Unbounded, Manrope и JetBrains Mono — из npm-пакетов `@fontsource-variable`, внешних скриптов и аналитики нет.

## Маршруты

- `#/` — «Экран запроса»;
- `#/results?query=…&top_k=10` (и `year_from`, `year_to`, `ipc`, если заданы) — выдача: данные запрашиваются по параметрам маршрута;
- `#/patent/<id>` — «Карточка патента» из последней полученной выдачи; отдельного запроса за карточкой нет.

Если параметры маршрута не проходят проверку API, выдача показывает «Запрос отклонён», в том числе в режиме `mock`: например, ссылка `#/results?query=Умный+полив&top_k=10`. При поиске с «Экрана запроса» этого не бывает: ввод проверяется до отправки.

## Структура

```text
frontend/
├── index.html             # страница (lang="ru"), тема до первой отрисовки
├── vite.config.ts         # плагины React и Tailwind, прокси /api → http://127.0.0.1:8000
├── .env.api               # VITE_API_MODE=api для npm run dev:api
├── public/favicon.svg     # значок-радар
└── src/
    ├── main.tsx           # точка входа, шрифты @fontsource-variable
    ├── App.tsx            # маршрут → экран; состояние формы и поиска
    ├── index.css          # Tailwind: цвета обеих тем, шрифты, анимации радара, скелетоны
    ├── api/               # types.ts (контракт), client.ts (mock | api), mock.ts, errors.ts
    ├── mock/search.json   # эталонный ответ API
    ├── lib/               # маршруты, проверка ввода, разбор answer, форматы, примеры, тема (theme.ts)
    ├── components/        # шапка и подвал, радар (RadarScope), карточки выдачи (ResultCards), сводка, плашка
    └── pages/             # SearchPage, ResultsPage, PatentPage
```
